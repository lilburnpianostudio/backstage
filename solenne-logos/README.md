# Solenne Naturals logo concept drafts

Starting points for refinement in a vector editor. They are not final art. Every file uses a `viewBox` with no fixed width or height, live `<text>` (not outlined), plain `<path>` shapes, and no filters, rasters, or external dependencies. Groups are named `mark`, `wordmark`, and `tagline`.

Wordmark type: `Georgia, Palatino, serif`. "Solenne" is set in title case, "NATURALS" in tracked-wide capitals, and the tagline in italic. Outline the text once the final typeface is chosen. Rendering at 200px and 2000px wide has been checked with the fallback serif fonts only, so confirm letter-spacing with Georgia installed.

## Variations

| File | Concept |
| --- | --- |
| `solenne-logo-A-minimal.svg` | Single-weight (3.5) line-art lotus in sage with gold water lines. Modern and quiet. |
| `solenne-logo-B-botanical.svg` | Filled, layered petals (lavender back row, blush front rows) with sage sepals and gold veins. Classic botanical-illustration feel. |
| `solenne-logo-C-geometric.svg` | Five bold petals rising from a gold half-sun. Fewest details, so the best candidate for a favicon or stamp. |
| `solenne-logo-D-organic.svg` | Blush and lavender bloom on a flowing stem with two sage leaves. The most illustrative and the least symmetrical. |
| `solenne-color-palette.svg` | Palette swatches with hex codes, plus black-only and white-only versions of marks A to D. |

## Palette

| Name | Hex | Use |
| --- | --- | --- |
| Sage | `#5B7553` | Primary: wordmark, outlines, leaves |
| Cream | `#F5F0E8` | Background |
| Gold | `#C5A55A` | Accent: rules, water lines, veins |
| Blush | `#E8C4B8` | Accent: petals |
| Lavender | `#B8A9C9` | Accent: back petals |

Pure black and white appear only in the one-color variants on the palette sheet.

## Notes for refinement

- Gold on cream has low contrast (about 2:1), so keep gold to decorative details and do not use it for text.
- Each logo file includes a cream `background` rect. Delete it for a transparent version. The line-art petals in A are filled with cream so overlapping petals hide each other.
- The lotus is a significant Hindu and Buddhist symbol. The brand owner chose it, but it may be worth keeping that in mind in how the mark is used and described.
